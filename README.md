# Smart Parking Projector — 빔 프로젝터 주차 유도 시뮬레이터

> 주차장 바닥에 **차량마다 다른 색의 유도선**을 빔 프로젝터로 투사해,
> 주차 요원 없이 한 번에 빈 자리를 찾아가게 하는 시스템의 **개념검증 시뮬레이터**입니다.

---

## 문제의식

주말 대형마트 주차장. 빈 자리는 분명히 있는데 다들 통로를 빙빙 돕니다.
안내 요원을 세워도 한 사람이 볼 수 있는 범위는 좁습니다.

**제안**: 입구에서 번호판을 인식해 차량마다 빈 자리를 할당하고,
바닥에 그 차 전용 색의 유도선을 투사합니다. 운전자는 자기 색 선만 따라가면 됩니다.

### 그런데 — 사람은 시키는 대로 하지 않습니다

이 시스템의 진짜 난제는 경로 탐색이 아닙니다.

> **비협조적 운전자가 안내를 무시하고 남에게 할당된 자리를 차지하면,
> 원래 그 자리의 주인은 어디로 가야 하는가?**

이 시뮬레이터는 그 돌발 상황에 관제 알고리즘이 얼마나 매끄럽게 대처하는지를 측정합니다.

---

## 연구 설계의 핵심 — 알고리즘은 커닝할 수 없습니다

시뮬레이터를 대충 만들면 관제 알고리즘이 "이 차는 배신할 차"라는 정보를 미리 알게 되어,
돌발 상황 대처 능력을 측정할 수 없게 됩니다. 그래서 코드를 세 계층으로 **물리적으로 분리**하고,
그 경계를 테스트로 강제합니다.

```
sim/world/     ① 주차장   도면 · 물리 · 센서 · 프로젝터
sim/control/   ② 관제     할당 · 경로 · 복구 전략     ← agents 를 import 하면 테스트 실패
sim/agents/    ③ 차량     운전자 성향 · 인지 · 판단   ← control 을 import 하면 테스트 실패
```

관제가 받는 것은 **실제 하드웨어가 줄 수 있는 센서 관측값뿐**입니다 —
입구 번호판 인식, 슬롯 점유 센서, 통로 검지기. 운전자의 비협조 성향은 볼 수 없습니다.
강탈은 오직 "예약자와 다른 차가 그 자리를 점유했다"는 **센서 신호로 사후에** 알게 됩니다.

```bash
pytest tests/test_layer_isolation.py     # 이 경계를 코드 레벨에서 검증
grep -rn "compliance" sim/control/       # 결과가 비어 있어야 정상
```

## 비교하는 것들

**복구 전략 6종** — 자리를 빼앗긴 차량을 어떻게 구제할 것인가

| 전략 | 요지 |
|---|---|
| `local_reassign` | 피해 차량에게만 최근접 빈 자리 재할당 |
| **`global_rematch`** *(기본값)* | 미주차 차량 전체를 헝가리안 매칭으로 재배치 — "모두 조금씩 양보" |
| `chain_shift` | 최소비용 증가경로로 예약을 연쇄 이양 |
| `reserve_pool` | 일부 슬롯을 예비로 남겨 즉시 투입 |
| `reputation_aware` | **관측된** 과거 이탈 이력으로 신뢰도를 추정해, 이탈 전력이 있는 운전자를 **달랜다** |
| `fairness_weighted` | 이미 여러 번 밀려난 차량에 우선권 |

여섯 전략은 **같은 시나리오·같은 시드** 위에서 전략만 바꿔 돌립니다.
`reputation_aware` 와 `fairness_weighted` 는 정확히 반대 방향입니다 — 하나는 규칙을
어긴 사람을 달래고, 하나는 규칙을 지키다 손해 본 사람을 보상합니다. 둘을 나란히
놓으면 "효율 대 공평"의 상충이 숫자로 드러납니다.

**베이스라인** — 안내가 없을 때 운전자가 알아서 찾아다니는 경우와 나란히 돌려,
탐색 시간·주행거리·통로 혼잡도를 비교합니다.

**시나리오** — 실험 조건은 코드가 아니라 `sim/scenarios/*.yaml` 에 있습니다.
`light`(여유) · `busy`(주말 오후) · `rush_hour`(만차). 강탈은 **자리가 귀할 때만**
일어납니다 — 빈 주차장에서는 비협조 운전자도 남의 자리를 건드릴 이유가 없습니다.

## 실행

Python 3.11 이상이 필요합니다.

```bash
pip install -e ".[dev]"

# 라이브 시뮬레이션 뷰어
uvicorn server.app:app --reload            # → http://localhost:8000

# 헤드리스 실행 (KPI만 확인)
python -m sim.world.simulation --duration 300 --arrival-rate 0.15

# 발표용 녹화본 만들기
python -m sim.metrics.trace_writer --duration 240 --out runs/demo

# 테스트
pytest tests/ -v
```

뷰어는 **라이브 스트리밍**(WebSocket, 배속·일시정지·도착률 조작)과
**녹화본 재생**(`trace.jsonl`)을 모두 지원하며 화면은 동일합니다.
서버에 연결하지 못하면 자동으로 녹화본으로 넘어갑니다.

> 전략 비교 배치 실험(`sim.experiments.run_matrix`)은 8단계에서 만듭니다.
> 지금 어디까지 왔는지는 [`docs/HANDOFF.md`](docs/HANDOFF.md) 를 보세요.

## 시각화

- 바닥은 실제 주차장에 가까운 **2D 평면**, 차량만 **3D**
- 유도선은 차선형이 아니라 **경로 중앙의 굵은 리본 + 진행 방향으로 흐르는 `<<` 쉐브론**
- **지나온 구간은 실시간으로 지워집니다**
- 차량마다 확실히 구분되는 고유색 (어두운 아스팔트 대비를 고려한 명도 범위)

> 스크린샷 자리

## 범위 밖 (의도적으로 구현하지 않음)

- **보상 정책** (재탐색을 당한 운전자에게 주차 할인 등) — 재탐색 횟수와 우회 거리를
  **기록만** 하고, 정책 설계는 별도 논의 사항입니다.
- 실제 번호판 인식 영상처리 — 완벽 인식으로 가정
- 프로젝터 캘리브레이션·왜곡 보정 — 이상적 투사로 가정
